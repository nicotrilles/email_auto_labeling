Here's what each file will do:
File	        Responsibility
------------------------------------
manifest.json	Tells Edge this is an extension
popup.html	    Defines the interface
popup.css	    Styles the interface
popup.js	    Handles user interactions and rules
icons/	        Extension icons

When you click the extension icon in Edge, a small Gmail Auto-Labeler window should appear.
